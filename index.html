Tentang Saya

Saya mahasiswa semester 3 Program Studi Teknologi Informasi, Fakultas Ilmu Komputer, Universitas Jember, dengan minat besar pada Web Development, Database, dan Data Science. Saya senang membangun solusi yang praktis dan mempelajari cara kerja setiap lapisan aplikasi — mulai dari tampilan yang dilihat pengguna sampai data yang tersimpan di baliknya.

Saya terbiasa merancang database relasional menggunakan MySQL dan PostgreSQL, serta menulis query yang membuat data tetap rapi dan cepat. Bagi saya, kode yang bersih, mudah dirawat, dan kebiasaan untuk terus belajar adalah kunci menjadi developer yang lebih baik.
